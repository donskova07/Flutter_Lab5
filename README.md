## Структура проекта
background.dart - отвечает за фон 
flagi - отвечает за появление флагов
main - отвечает за включение приложения
text - отвечает за то, как выглядит текст
## Как запустить

- git clone <ссылка на репозиторий>
- cd <папка проекта>
- flutter pub get
- flutter run -d chrome
